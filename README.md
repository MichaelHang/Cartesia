# Geometry Board — 数学画图工具

纯前端（原生 JavaScript + Canvas，零依赖、零构建）的交互式几何画板。

## 功能

- **绘制**：点、线段、直线、射线、圆、多边形（点击加顶点，双击或回起点闭合；快捷键 V/P/S/L/C）
- **作图**：垂线、平行线、中点、角平分线、垂直平分线
- **测量**：距离、角度（三个点，第二个为顶点）、多边形面积
- **变换**：平移、旋转（可设旋转中心，Shift 吸附 15°）、镜像
- **函数图像**：显式函数（`2x+1`、`sin(x)`、`x^2`）与隐式方程（`y^2=8x`）
- **样式**：颜色、线宽、线型、内部填充——封闭图形默认只描边不填充，"填充"滑块拉高后叠加淡色内芯（描边始终不透明）；样式修改可撤销
- **其他**：文字标签、吸附到网格/点、撤销/重做、PNG / SVG 导出、重置视图

## 运行

项目使用 ES Module，**必须通过 HTTP 访问**——直接双击 `index.html` 会被浏览器的 CORS 策略拦截，页面空白。

```bash
python3 server.py           # 启动后访问 http://localhost:8643
python3 server.py 9000      # 自定义端口
```

也可以用任何静态服务器（`npx serve`、nginx 等）；`server.py` 自带 no-cache 响应头，开发时改完代码刷新即见。

## 部署

纯静态站点，无需构建：把整个目录原样上传到任意静态托管即可。以 Cloudflare Pages 为例——连接 GitHub 仓库后，Framework preset 选 **None**、Build command **留空**、Build output directory 填 **`/`**。此后每次 `git push` 自动重新部署。`server.py` 仅本地开发使用，不参与线上运行。

注意：`index.html` 里 JS/CSS 引用带 `?v=` 版本号，修改代码后请递增，避免托管平台的边缘缓存让访问者拿到旧文件。

## 快捷键

| 按键 | 功能 |
|---|---|
| V / P / S / L / C | 选择 / 点 / 线段 / 直线 / 圆 |
| F / T | 函数 / 文字 |
| 拖动 / 中键或 Alt+拖动 | 框选 / 平移视图 |
| 滚轮 | 缩放 |
| Delete / Backspace | 删除选中对象（任何工具下） |
| Esc | 取消当前操作 / 清除选择 |
| Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z） | 撤销 / 重做（含样式修改） |

## 架构

```
index.html        页面结构、工具栏、模态框
favicon.svg       网站图标（坐标系 + 抛物线）
css/style.css     深色主题样式
js/Geometry.js    向量与几何数学库（Vec2、求交、多边形面积……）
js/Canvas.js      坐标系管理：变换、缩放平移、网格与坐标轴绘制
js/Objects.js     几何对象类（点/线/圆/多边形/函数/角/文字/测量）与绘制
js/Tools.js       21 个交互工具（继承 BaseTool，注册于 TOOL_MAP）
js/History.js     命令模式撤销/重做栈
js/main.js        入口：事件接线、渲染循环、面板与导出
server.py         本地开发服务器（仅本地预览用，不参与部署）
```

渲染为即时模式：每次交互全量重绘画布；右侧对象列表按内容签名做脏检查，只在变化时重建 DOM（事件用委托绑定）。

## 已知限制

- 函数表达式通过 `new Function` 在本地求值（已加关键字黑名单，仅允许纯数学表达式），仅供本地工具使用，勿将求值内容来自不可信来源的场景。
- 暂不支持触屏（仅鼠标事件）。
- `serialize()` 目前只服务于旋转工具的状态快照，尚未接保存/加载文件功能。
